# Changelog

All notable changes to `washington_apples.csv` and `washington_apples.xlsx` will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-11-20

### Added
- Initial release of `washington_apples.csv` and `washington_apples.xlsx` (`37` records and `7` columns: `apple_id`, `variety_name`, `flavor_profile`, `crispness_level`, `skin_color`, `harvest_window`, and `origin`).
- Coverage of `37` commercial apple varieties (`WA_APP_001` to `WA_APP_037`) across `13` origins, compiled from Washington apple reference sources with zero missing values and zero duplicate records.
- Encoding validation and import verification in R and Python, along with `README.md`, `data_dictionary.csv`, and `CITATION.cff`.
